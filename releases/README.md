# Проектные часы — Windows 10 / 11 (64 бит)

Готовое локальное приложение для месячного учёта часов сотрудников.

1. Скачайте [ProjectHours-Windows.zip](./ProjectHours-Windows.zip) с GitHub кнопкой **Download raw file**.
2. Полностью распакуйте архив в постоянную папку.
3. Дважды щёлкните **Создать ярлык на рабочем столе.vbs**.
4. Открывайте **Проектные часы** с рабочего стола.

Python включён в архив. Терминал не нужен. Для окна приложения нужен
установленный Microsoft Edge или Google Chrome. Интернет для работы не требуется.

Закрытые проекты зелёные; только их часы входят в итог месяца. Незакрытые
проекты красные; часы сохраняются, но исключаются из итога. Есть индивидуальные
и общие отчёты команды, экспорт CSV для Excel и печать.

Данные хранятся в `%LOCALAPPDATA%\ProjectHours\hours.sqlite3`, отдельно от
программы. Между разными компьютерами эта локальная версия не синхронизируется.

В архиве нет пользовательских отчётов. Прошли 14 автоматических тестов;
запуск окна Chromium и завершение локального сервера проверены на Linux.
Сам запуск ярлыка и окна Edge на реальной Windows требует проверки.
